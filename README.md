## 🚀 Cách Dùng Siêu Nhanh (1 Phút Tích Hợp)

### Cách 1: Nhúng Thẻ HTML Tự Động (No-Code)
Chèn đoạn script và thẻ `<div>` vào bất kỳ vị trí nào trên website:

```html
<script src="https://huyhoang2k5.github.io/vietqr-widget/vietqr.js"></script>

<div data-vietqr 
     data-bank="tpbank" 
     data-account="20058999999" 
     data-amount="50000" 
     data-memo="DONHANG123">
</div>
```

### Cách 2: Gọi Hàm JavaScript
```javascript
import VietQR from 'https://huyhoang2k5.github.io/vietqr-widget/vietqr.js';

const qrUrl = VietQR.getUrl({
  bank: 'tpbank',
  account: '20058999999',
  amount: 100000,
  memo: 'THANHTOAN_PRO'
});

console.log(qrUrl);
```
